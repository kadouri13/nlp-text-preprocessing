# NLP Text Preprocessing (TP 1)

Comprehensive NLP text preprocessing toolkit in Python. Features text cleaning, regex entity extraction, sentence and word tokenization, Arabic clitic segmentation, Byte-Pair Encoding (BPE) from scratch, normalization, and pipelines for TF-IDF and Transformer models.

## Contents
- **Part 0:** Setup & Datasets
- **Part 1:** Cleaning with Plain Python (Loops, conditions, string methods)
- **Part 2:** Regular Expressions & Advanced Cleaning (BeautifulSoup, entity tagging)
- **Part 3:** Tokenization (Word, Sentence, Arabic clitics, Byte-Pair Encoding)
- **Part 4:** Normalization (Contractions, accents, Arabic normalization, elongation, stop words)
- **Part 5:** Complete Pipelines (Classic models vs Transformers)
